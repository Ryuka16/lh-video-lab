# 教学视频库 · lh-video-lab

> **EN** · A Foundry VTT GM utility for sending short teaching clips and images to players — organize media into virtual groups, upload local files or browse the whole server, then whisper to one player or broadcast to all via chat.

把常用的 10~15 秒教学短视频（图片也行）收进一个固定文件夹，GM 一键把它私聊发给某位玩家，或群发给全体玩家的聊天栏——对方点播放即看，不用自己翻 Journal。

## 能做什么

- **固定素材文件夹**：可点「选择文件夹…」用官方文件夹选择器可视化挑选，不用手输路径。
- **虚拟收藏分组**：把素材拖进分组块即可归组（纯 UI 收纳，不动服务器文件），可新建 / 删除分组、组内移出。
- **导入素材**：本地上传（图片 / 视频），或浏览服务器全目录挑图。
- **剪贴板粘贴 / 拖入导入**：面板打开时 Ctrl+V 粘贴，或把图片/视频文件直接从文件夹拖进面板——统一进「导入面板」；一次多个文件只出一个面板（可继续追加），逐行预览、改名、选「留存（素材文件夹）/不留存（临时目录 vlab-temp，默认）」，勾选是否发送后一次性导入。
- **清理临时**：底部「清理临时」打开浏览面板——列出 vlab-temp 里全部文件，每行可预览（图片灯箱 / 视频新标签播放）、按当前接收人发送到聊天、点文件名或「复制」按钮复制文件路径；底部显示临时文件夹地址 `Data/vlab-temp/` 并有一键复制按钮。FVTT 源码不支持删除文件（游戏内任何模块/宏都删不掉），所以面板里提示：请到该地址手动删除——自托管用户到服务器上删 `Data/vlab-temp/` 里的文件，平台托管（Forge / Molten）用户用平台网页文件管理删，删完回面板点「刷新」重新统计。
- **左右分栏**：左侧素材列表，右侧 200px 小预览；图片点击弹大图灯箱，视频用原生播放条 + 全屏。
- **一键发送**：选「全体玩家」或「某位玩家私聊」，发到聊天栏即看。
- **聊天图片放大**：GM 端点击弹灯箱，玩家端开新标签看原图。
- **改名**：只改显示名（不动磁盘文件），真实文件名灰色小字保留。
- **5 套配色 + 窗口记忆**：深空蓝 / 蓝白 / 紫绿 / 鎏金黑 / 薄荷；窗口位置、大小、配色关闭时记住，下次原样恢复。
- **状态持久化**：左栏状态存 GM 浏览器本地，换世界包、升级模块都不变，可导出 / 导入备份。
- **只装 GM 一端**：玩家无需安装此模块。

## 安装

**方式一 · 一键安装（推荐）**

打开 Foundry 的「安装模组」窗口 → 底部「清单 URL」粘贴这一行 → 点「安装」：

```
https://raw.githubusercontent.com/Ryuka16/lh-video-lab/main/module.json
```

**方式二 · 手动安装**

1. 下载 [Releases](https://github.com/Ryuka16/lh-video-lab/releases) 里的 `lh-video-lab.zip`，解压后把 `lh-video-lab/` 文件夹放进 Foundry 的 `Data/modules/`。
2. 设置 → 模块 → 启用「教学视频库」。
3. 刷新页面（Ctrl + F5）。

**兼容性**：Foundry VTT 13.0.0 及以上（13.351 已验证）· dnd5e 5.3.0 及以上 · 只在 GM 端安装即可，玩家无需安装。

## 使用

- 进入游戏后，画布左侧工具按钮多出「🎬 教学视频库」（仅 GM 可见）。
- 选文件夹 → 应用；点「新建分组」起名后，把素材拖进分组块归类。
- 导入：点「本地上传」或「浏览服务器」挑图。
- 预览：点左侧素材，右侧小预览显示；图片点它放大。
- 发送：选接收人 → 点「发送」→ 聊天栏弹出。
